    Questions

    Why do you ask for my phone digits?

    So only you can see your ticket. Anyone could guess a code, but not the code and your number together. We never show your number on this page.

    How up to date is this page?

    It shows what our technicians record, as they record it. While a ticket is open on your screen, the page checks for changes every 30 seconds by itself.

    My code doesn't work

    Check it against your receipt or our message. Repair and warranty codes never use the look-alike characters 0, O, 1, I, 5, S, 8 or B, so the page tells you when one has crept in.

    Use the last 4 digits of the number you gave us when you placed the order. If it still doesn't work, message us and we'll look it up.

    What does "Remember on this phone" keep?

    The code and the 4 digits, stored only in this browser, so you can check again with one tap. Nothing goes to us. Tap the cross beside a ticket to forget it.
